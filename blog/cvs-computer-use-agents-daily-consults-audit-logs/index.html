CVS runs computer-use agents on tens of thousands of consults a day

CVS Health has OpenAI computer-use agents in production handling the system steps for tens of thousands of consults a day, checked through screenshots and action logs, according to Becker's and The Decoder.

Case studyGovernance

OpenAI announced computer-use agents for healthcare on November 16, built with CVS Health, Cigna Healthcare, Abridge and Ambience Healthcare for work like referrals, prior authorizations and discharge planning1. CVS is the one with agents in production. Becker's Hospital Review reports that one CVS agent cleared a monthslong document backlog over a weekend, and another handles the system steps for tens of thousands of consults each day1. Cigna's case managers used to move between more than 10 clinical and administrative systems, and its CIO Madhu Nutakki said the work went from concept to deployment in under eight weeks1.

The controls matter as much as the throughput. HIT Consultant describes the CVS consult agent as running under human oversight and screenshot verification, and lists human in the loop checkpoints and action by action audit logs as part of the design2. The Decoder adds that CVS keeps the data inside infrastructure it controls and reviews the agents' work through screenshots and action logs3. Ambience showed an agent that stops and asks a clinician when a record is ambiguous, though that was a demonstration, not a live deployment1.

The headline safety number needs care. Reviewers rated 99% of 325 EHR inbox tasks handled by GPT-6 Astra as clinically safe1, but that is OpenAI's own evaluation relayed by the press, not a measure of patient outcomes. The CVS backlog and consult figures are also company claims without a published error rate.

For data teams, computer-use agents click through the same screens people do, so the audit trail is screenshots and action logs rather than clean API calls. That trail is only useful if it lands somewhere queryable: each action tied to an agent version, a source record, the human who approved it and the outcome. Access control also moves up a level, since the agent can reach whatever the configured application allows3.

One step this week: for any agent that drives a user interface, check whether its action logs are retained, joined to the records it touched, and sampled by a person on a fixed schedule.
